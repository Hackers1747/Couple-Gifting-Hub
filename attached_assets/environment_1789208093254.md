# Environment Variables

Every variable below is read somewhere in the current code (paths given). No
values are included — names and purpose only.

| Variable | Required? | Read in | Purpose |
|---|---|---|---|
| `PORT` | Required (throws if missing/invalid) | `artifacts/api-server/src/index.ts`, `artifacts/heartdrop/vite.config.ts` | Port the API server listens on / port Vite dev-serves the frontend on. Separate values for each package. |
| `BASE_PATH` | Required (throws if missing) | `artifacts/heartdrop/vite.config.ts` | Vite `base` path for the built frontend; also used to derive `wouter`'s router `base` at runtime (`import.meta.env.BASE_URL`). |
| `DATABASE_URL` | Required by `@workspace/db` (throws on import if missing) | `lib/db/src/index.ts` | Postgres connection string for Drizzle ORM. **Not currently imported by `artifacts/api-server`**, so in practice nothing breaks today if unset — see [architecture.md](./architecture.md). |
| `GEMINI_API_KEY` | Optional | `artifacts/api-server/src/routes/ai.ts` | Enables real Gemini message generation (`gemini-2.5-flash`). Without it, all AI routes fall back to canned template text. |
| `RAZORPAY_KEY_ID` | Required for payment flow | `artifacts/api-server/src/routes/payment.ts` (`Razorpay` client), `artifacts/heartdrop/vite.config.ts` (injected client-side as `VITE_RAZORPAY_KEY_ID`) | Razorpay public key id. |
| `RAZORPAY_KEY_SECRET` | Required for payment flow | `artifacts/api-server/src/routes/payment.ts` | Razorpay secret key — used both to create orders and to HMAC-verify the payment signature on `/api/payment/verify`. Route will throw if unset when a payment is attempted (non-null assertion in `getRazorpay()`). |
| `SUPABASE_URL` | Required by `lib/supabase.ts` (throws on import if missing) | `artifacts/api-server/src/lib/supabase.ts` | Declared for a Supabase integration; **the module isn't currently imported by any route**, so it has no effect unless something starts importing it. |
| `SUPABASE_SERVICE_ROLE_KEY` | Required by `lib/supabase.ts` (throws on import if missing) | `artifacts/api-server/src/lib/supabase.ts` | Same caveat as `SUPABASE_URL`. |
| `WHATSAPP_PHONE_ID` | Optional | `artifacts/api-server/src/routes/whatsapp.ts` | Meta Cloud API phone number id. Without it (and the token below), WhatsApp sends are logged to console instead of actually sent. |
| `WHATSAPP_ACCESS_TOKEN` | Optional | `artifacts/api-server/src/routes/whatsapp.ts` | Meta Cloud API access token — see above. |
| `REPL_ID` | Optional, Replit-provided | `artifacts/heartdrop/vite.config.ts` | When present (and `NODE_ENV !== "production"`), enables Replit's dev-only Vite plugins (`cartographer`, `dev-banner`). Not something you set yourself — Replit injects it. |
| `CI` | Set by `.replit` deployment config | `.replit` (`[deployment.postBuild] env`) | Passed to the post-build `pnpm store prune` step. |

## Practical gaps this implies

- The app will currently run and serve traffic with only `PORT`, `BASE_PATH`,
  `RAZORPAY_KEY_ID`, and `RAZORPAY_KEY_SECRET` set — `DATABASE_URL` and the two
  `SUPABASE_*` vars are only enforced if/when something imports those modules,
  which nothing does today.
- If you do start importing `@workspace/db` or `lib/supabase.ts` without setting
  their required vars, the server will crash on startup (both throw at module
  load, not at first use).
